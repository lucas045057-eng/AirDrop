# 管理功能投产范围

用户确认本次先投产管理功能，并保留执行限制。

| 功能 | 状态 |
|---|---|
| 登录、会话、CSRF | 已开放 |
| EVM/Solana 钱包生成、导入、分组 | 已开放 |
| 加密备份、恢复、本地解密与导出 | 已开放 |
| 单项/批量删除与关联保护 | 已开放 |
| 脚本上传、分析、版本、Diff 和审核 | 已开放 |
| 规则适配、审核后的外部 AI 请求 | 已开放；外部 API 由管理员配置 |
| 项目绑定、任务资料、停用计划与审计 | 已开放 |
| 脚本执行、重试、自动调度 | 后台与界面关闭 |
| 真实签名、RPC、广播与空投领取 | 未实现且未开放 |

演示初始化、模拟交易和模拟 AI Provider 已移除；仓库不再提供演示源码、业务数据、教程或截图。生成的密钥仍是有效的随机 EVM/Solana 密钥，关闭执行不影响备份和导出。

保留独立 Worker/Runner 和队列协议以兼容数据结构。管理模式 Worker 只维持健康状态，不领取任务或触发计划。隔离引擎回归不代表部署可以执行真实链上操作。

尚未完成受控签名、真实 RPC、Gas/nonce 与链上确认、主密钥轮换、多用户权限、外部告警或长期稳定性验收；未验收 PostgreSQL。
