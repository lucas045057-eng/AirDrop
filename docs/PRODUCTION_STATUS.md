# 生产状态与上线边界

生产部署立场仍是先开放管理功能。仓库现在包含独立原生运行路径，但新增运行能力默认关闭；本地测试通过不能代表已经获准部署或已在目标主机验收。

## 功能状态

| 功能 | 代码状态 | 当前上线立场 |
|---|---|---|
| 登录、会话、CSRF | 已实现 | 管理功能可用 |
| EVM/Solana 钱包、加密备份与恢复 | 已实现 | 管理功能可用；主密钥需单独保管 |
| 脚本上传、静态发现、AI 审核、Diff 与版本 | 已实现 | 管理功能可用；外部 AI 请求需逐次审核 |
| 人工适配上传、同包新版本、Diff 与重新扫描 | 页面流程已接通并通过隔离浏览器回归 | 代码变更不代表适配业务已正确；须逐版审核 |
| 项目绑定、脚本账号资料、冲突导入 | 已实现 | 管理功能可用；敏感字段加密保存 |
| 原生运行定义、环境构建、任务快照、容器 Worker | 主体代码与假 Docker 回归已覆盖；目标 Linux 未验收 | `AIRDROP_NATIVE_EXECUTION_ENABLED=false`；目标 Linux 主机验收前不开放 |
| 原生日志、状态回写、手动核查与再次运行 | 已实现；本地测试覆盖 | 不代表真实业务结果已验证；仍须逐次核对 |
| 旧模拟执行与自动计划 | 旧路径保留 | `AIRDROP_EXECUTION_ENABLED=false`；不随原生运行开关启用 |
| 真实服务登录、签名、RPC 与链上确认 | 未做目标服务验收 | 不作为已验证能力宣传 |

默认配置应同时保持 `AIRDROP_EXECUTION_ENABLED=false` 和 `AIRDROP_NATIVE_EXECUTION_ENABLED=false`。演示初始化、模拟交易和模拟 AI Provider 已移除；生成的钱包仍是真实随机密钥，执行关闭不影响备份和导出。

## 验收证据与限制

本分支的测试在隔离数据库和临时目录运行。智能分析浏览器流程用临时数据库与假 AI，不执行上传代码；2026-10-16 本地回归 24 项通过，其中包含人工适配上传、同包版本、Diff 与重新扫描。原生浏览器流程用假 Docker、回环控制器和生成的钱包，正式经由项目中心运行按钮完成；21 项检查通过，覆盖独立 Worker、状态回写、日志分页/下载、资料导入和页面恢复。前端生产构建通过；后端全量测试 317 passed。以上结果不代表 Linux、生产运行或真实业务通过。

用户桌面存在 `savior.zip`。本次只读列出压缩包并用 AST 查看入口/调用关系；包内还含账号、状态和历史日志数据，未导入、执行、解压到产品目录或把这些数据复制进仓库。尚未制作脱敏验收副本，也未适配 Savior“仅验证”和“每日签到”，更未做业务逻辑对照。Linux Docker 网络隔离、iptables/nftables 规则、cgroup 限额、tmpfs、宿主资源、生产备份恢复及目标服务受控账号均未在生产主机验收。请按 [部署与升级](DEPLOYMENT.md) 的原生运行步骤完成这些现场检查。

原生脚本一次在独立容器中运行并自行管理钱包批次、并发与业务判断。进程退出码不等同于钱包业务成功；没有结构化结果时平台明确显示“未收到单钱包结果”。不自动重试或自动调度；未知状态保留锁并要求人工核查。

尚未完成真实服务兼容性、主密钥轮换、多用户权限、外部告警、长期稳定性或 PostgreSQL 验收。不得以本地回归结果替代这些验证。
