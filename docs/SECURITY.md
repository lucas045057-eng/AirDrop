# 密钥与备份

数据库私钥使用认证加密，普通 API 和列表只返回公开地址与元数据。加密依赖实例主密钥；管理员密码不能替代主密钥。升级不得重新生成已有主密钥。

钱包备份使用自选密码，经 PBKDF2-SHA256（600000 次）派生密钥后以 AES-GCM 加密。密码与文件分别保管，忘记密码不能重置旧文件；钱包仍存在时可重新下载新备份。

浏览器解密使用 Web Crypto，禁止网络连接和表单提交，不使用浏览器持久存储。导出的 JSON 包含明文私钥；关闭页面不删除已下载文件。

会话使用 HttpOnly Cookie，公网 HTTPS 启用 Secure Cookie，写操作验证 CSRF 和来源。实际密码、AI 密钥、数据库、SSH 私钥和部署配置不进入 Git。升级保留现有管理员资料。

静态检查和脱敏不能证明任意源码安全。外部 AI 请求需要审核脱敏预览，钱包库私钥不会发送给 AI。管理模式关闭脚本执行、调度、RPC 和签名。

Runner 保持无网络、无数据库/主密钥、只读根目录与资源限制；容器隔离不替代真实资金签名架构。数据和主密钥分别备份，并验证恢复。
