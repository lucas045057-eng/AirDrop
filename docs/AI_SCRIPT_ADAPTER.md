# AirDrop V2.1 智能脚本接入

本模块扩展现有 V2 的脚本包、加密工件、管理员认证和任务管理。开发分支为 `feature/v2.1-smart-adapter`，基线为 `dc7e96c146cfade5458e521a38a9ac72eb003cee`。本次开发没有访问生产服务器、推送仓库或调用真实外部模型。

## 网页操作

1. 在脚本中心上传 `.py`、`.zip`、`.tar.gz` 或 `.tgz`。原上传安全阈值保持：10 MiB 上传体积，以及原有解压、路径、数量和深度限制。上传解析在单个受限子进程进行，不导入或运行包内代码。
2. 点击版本旁的 **智能分析**，选择 **开始结构发现**。页面显示实际阶段。Worker 未启动时任务保留在有界队列，页面会提示离线。
3. 查看候选功能、实际源函数、调用依赖、共享状态、参数、钱包字段角色和行号证据。只选择需要适配的功能。未知结构、动态调用、安全检查、验证码和资金操作会说明具体阻塞原因。
4. 不启用 AI 时，规则引擎仅为已经可以独立调用的安全候选生成轻量入口。需要参数提取时，勾选已有 AI Provider；它沿用系统设置的 URL、模型和加密密钥。
5. 检查完整脱敏预览、Provider 和 SHA-256，主动勾选确认并批准。未批准不会发送；改变源码、选项或 Provider 必须新建任务并重新审核。一次任务最多一个模型请求，没有自动网络重试。
6. 查看草稿摘要并按文件、每页最多 120 行阅读 Diff，检查配置和风险，逐项批准或拒绝功能。高风险、未解决交互、未知参数类型等功能不能批准。仅将已批准功能保存为新版本；原版本不覆盖。
7. 下方选择一个已审核功能，入口自动关联。填写必要参数，源码明确的默认值会带出；选择项目或直接新建项目，可调整钱包来源及字段角色，保存独立管理任务。敏感参数仅允许引用名称，不接受实际凭证。
8. 刷新页面会根据地址中的版本与任务 ID 恢复分析记录、预览、草稿或已保存功能。失败时可重新发现并针对所选功能重新提交；新 AI 请求必须重新审核。可以取消对应分析，也可以永久清理已终止的分析记录。清理保留原版本和已保存版本，分析 Diff 会随记录删除。

**功能任务只能保存配置。执行、隔离运行、签名、RPC、交易和自动调度保持关闭。** 原有 V2 单入口管理接口继续有效；不能通过旧版本批准接口绕过新功能逐项审核。

## 工作流程

`DISCOVER` 任务进行静态扫描，返回可追溯结构；无需 AI。`TRANSFORM` 任务对选择的实际功能重新扫描，规则模式直接生成，AI 模式先生成加密的不可变预览，等待明确批准，再请求模型并校验产出。

上传：API 接收有界文件 → 受限可信解析子进程 → 原始及源码加密工件。

分析：持久化任务 → 独立 Adapter Worker → 受限静态子进程 → 可选且已审核的模型请求 → 受限校验子进程 → 加密草稿 / 分页 Diff → 逐功能人工审核 → 原子保存新版本。

Adapter Worker 和运行上传代码的 Runner 分开；不挂载 Runner 总线、不安装上传依赖、不开放 Runner 网络。

## 静态分析能力与边界

解析多文件 AST、相对导入、别名、实际可解析的调用图、函数、类、主入口、菜单分支、CLI 注册、参数和共享全局变量。支持 input/getpass/sys.stdin、Click/Typer、Rich Prompt/Confirm/Console、questionary/inquirer、argparse 子命令、异步函数及多入口。可解析包装函数的交互沿调用链传播。

菜单分支和 CLI 命令优先成为候选；辅助函数通过依赖呈现。无明确入口的模块，未被调用的公开根函数仅为 UNKNOWN 候选，不宣称它们全部是业务功能。动态分发、实例/嵌套绑定、复杂装饰器、默认表达式、导入副作用、复杂共享会话与业务顺序不能保证静态推断，需人工确认。当前不提供图形依赖编辑器。

钱包适配仅识别格式、文件/配置引用和字段角色，实际数据文件不参与外部分析；没有向钱包表增加业务字段。无法确认来源或所需配置时明确显示未知/缺失，不填占位私钥。动态文件路径、复合数据处理与运行时业务依赖不会猜测。

## 受控重构

生成文件只允许 `airdrop_generated/` 单层 Python 文件，单文件 64,000 字节、最多 20 个、全部模型产出最多 512,000 字节。入口只轻量导入、调用或 await 所选实际函数，不复制业务、执行菜单输入或附带额外副作用。

有限补丁只允许已存在 Python 文件。允许将明确 input 赋值及 int/float/str/bool 转换提取为显式参数；交互以外的业务 AST、原有函数、模块配置、启动逻辑、敏感模块不可改变。复杂重构转人工处理。产出重新扫描，参数 Schema 与实际函数签名逐项一致。参数类型和缺失默认值不会由规则猜测。

模型返回任何路径、代码、安全判断、置信度均不可信；严格协议、实际来源、行号、语法、依赖、风险和入口关联校验独立于模型。规则置信度和模型估计均不是验证过的成功概率。批准代码表示完成管理审核，不表示已执行或验证链上行为。

Click 命令对象另有业务 callback，自动入口只调用已识别的 callback，不启动 CLI 参数解析。使用当前 Context、选项验证回调、复杂 CLI 类型或上级分组前置逻辑时转人工处理，不跳过验证或初始化；argparse.parse_args 与 sys.argv 运行时读取也会阻塞自动批准。Click 对象与上下文行为参考 [官方 API](https://click.palletsprojects.com/en/stable/api/)。

## 失败、删除与回滚

排队/运行的取消只影响该任务及其子进程/请求。错误不会改动原版本或产生半个批准版本。租约失效后静态任务最多恢复一次；已经标记模型请求发送的任务转 MANUAL_REQUIRED，禁止自动重放。

源版本存在分析、草稿或任务引用时禁止删除。终止任务可先清理分析记录，再按现有删除接口清理不被引用的版本；仍被任务引用的已保存版本受保护。孤立工件清理检查旧版本和新表全部引用。同一物理加密文件被其他工件复用时保留。

功能任务的版本不可直接切换；换版本须选择新版本对应的已审核功能新建任务。旧任务继续使用原有 Manifest 和回滚规则。撤回尚未保存的草稿不会改动旧版本。数据库回退方法见部署文档。
