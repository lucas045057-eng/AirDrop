# AirDrop V2 操作流程

当前平台管理钱包、项目、脚本和任务资料。执行、自动调度及链上交易尚未开放，页面显示“管理模式 · 执行未开放”。

## 钱包与分组

1. 钱包中心 → 生成钱包，选择 EVM 或 Solana、数量（1–1000）和分组。
2. 下拉列表显示已有分组及钱包数量，默认使用当前查看的分组。选择“＋ 新建分组”后填写名称；取消不会创建空分组。
3. 导入使用同一分组选择器，支持 TXT/CSV/XLSX/JSON 和明确字段映射。私钥加密保存，不在普通列表显示。
4. 生成或导入后下载加密备份并执行恢复验证。分组数量及当前列表自动刷新。

## 备份与私钥导出

钱包中心 → 加密备份，设置至少 12 字符的密码并下载 `.enc` 文件。备份密码由你设置，平台不保存明文，管理员登录密码不是备份密码。备份包含全部钱包，不受当前分组或搜索限制。

钱包中心 → 解密备份 → 选择 `.enc` 文件 → 输入备份密码 → 勾选钱包 → 下载私钥 JSON。解密在浏览器本地完成，文件、密码和解密得到的私钥不上传；关闭或清空会重置状态。导出的 JSON 包含明文私钥，请自行保管。

钱包中心 → 恢复验证，可仅验证文件与密码，也可恢复缺少的钱包。忘记旧密码无法重置旧文件；钱包仍在平台时可重新设置密码下载备份。

## 脚本、项目与任务

脚本中心上传 `.py`、`.zip` 或 `.tar.gz`，查看结构、入口和脱敏源码。上传不执行代码，请先移除硬编码凭证。

适配选择规则式适配，或在系统设置配置外部兼容 API。外部 AI 发送前须审核脱敏预览及其 SHA-256。检查 Diff、Manifest 和钱包映射后批准保存版本。

项目中心可创建项目、绑定分组或部分钱包、设置时区与业务周期。任务资料可以保存；测试、运行和发布需要执行验证，当前管理模式不能执行或完成发布。计划只允许保存为停用状态。

## 删除

勾选钱包或全选当前列表 → 批量删除 → 检查名单并确认。无引用项永久删除，有关联项保留并显示原因。切换分组或搜索条件清空选择。钱包删除清除数据库中的加密私钥，需要时先备份。

有关联的数据按“计划 → 已结束执行 → 任务 → 项目或解除绑定 → 钱包/分组 → 脚本版本”清理。删除分组保留钱包；删除计划保留执行；运行中或待核查记录先核查。审计记录保留。
