# 永久删除规则

删除需管理员会话、CSRF 和明确确认；关联项保留并显示原因，不强制清空历史。

| 对象 | 规则 |
|---|---|
| 钱包 | 清除无引用钱包、加密私钥和分组关系；项目绑定、结果、积分、锁和交易意图阻止删除 |
| 钱包批量删除 | 最多 1000 个 ID；删除无引用项，保留关联项，返回逐项原因 |
| 分组 | 删除分组与成员关系，保留钱包；项目分组绑定阻止删除 |
| 项目 | 删除无任务/历史引用的项目并解除绑定 |
| 任务 | 删除无执行/计划引用的任务及其工作流 |
| 计划 | 删除计划及发生记录，保留执行 |
| 已结束执行 | 删除日志、结果和积分，保留周期凭据以防重复运行 |
| 脚本版本 | 删除无任务/历史引用的版本及适配信息，清理无引用加密工件 |
| AI 配置 | 清除地址、模型与加密密钥，规则适配保留 |

按“计划 → 已结束执行 → 任务 → 项目/解除绑定 → 钱包/分组 → 从新到旧的脚本版本”清理。运行中或待核查记录先核查，审计保留。钱包删除不删除已下载备份。

批量接口为 `POST /api/wallets/bulk-delete`，提交 `confirmed: true` 和 `wallet_ids`。审计失败整批回滚。全选仅作用于当前列表，切换分组或搜索清空选择。
